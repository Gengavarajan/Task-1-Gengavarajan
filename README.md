# 🎯 Number Guessing Game

A Java-based Number Guessing Game developed as part of my Java Programming Internship. This project generates a random number and challenges users to guess it within a limited number of attempts while providing helpful hints after each guess.

## 🚀 Features

- Random number generation
- Interactive user input
- Hint system (Too High / Too Low)
- Tracks the number of attempts
- Winning and losing conditions
- Simple console-based interface

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Scanner Class
- Random Class
- Conditional Statements
- Loops

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone <repository-link>
   ```

2. Open the project in IntelliJ IDEA, Eclipse, or any Java IDE.

3. Compile and run the Java file:

   ```bash
   javac NumberGuessingGame.java
   java NumberGuessingGame
   ```

4. Enter your guesses and follow the hints provided by the program.
